## 11. 执行前最终门禁

- [ ] 用户已看到第 1—9 节完整报告。
- [ ] 用户批准原文精确包含本申请编号。
- [ ] 申请状态为 `APPROVED_ONCE`，未过期且从未使用。
- [ ] 环境 ID、主机指纹、Git SHA、ChangePlan 哈希均未变化。
- [ ] 精确目标、数量、选择器和哈希均未变化。
- [ ] 不存在新增的非删除替代方案。
- [ ] 备份可读，恢复演练为 `PASS`。
- [ ] 拟执行动作与报告完全一致，不包含未解析变量或通配符。
- [ ] 最大影响、停止条件、监控和执行后验证已就绪。
- [ ] 无任何一项“不确定”。

任一项未满足：停止，不执行，并保持现场不变。任何字段变化：将本申请标为 `EXPIRED`，重新提交新编号申请。
