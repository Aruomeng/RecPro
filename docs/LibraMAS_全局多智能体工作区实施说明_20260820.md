## 1. 当前实际产出

本轮已将 8 个既有业务 Agent 从推荐页局部展示提升为全局、会话级协作层。Orchestrator 只负责编排，不计为第九个 Agent。所有一级路由共享同一个 Agent Workspace 和右侧工作栏，页面切换不会重新创建会话。

后端新增了纯内存 Workspace、512 条有界事件缓冲、32 个活跃会话上限、15 秒 SSE heartbeat、10 分钟续传保留、白名单 observation、结构化 Directive、身份隔离、幂等观察和公开字段过滤。常驻感知只执行确定性本地策略，不调用 DeepSeek，也没有持久化端口。

推荐任务通过可选 `X-Agent-Workspace-Id` 把真实 Orchestrator 事件镜像到全局时间线；反馈接口把实际返回的 `FeedbackLearningAgent` 动作汇入同一 Workspace。没有该 Header 的旧客户端保持原行为。无效 Workspace 会在占用推荐并发槽或调用反馈服务之前返回 404。

本地外部情境适配器提供开放安排、学术日历和馆内活动，统一标记为 `EXTERNAL_DEMO`，缓存 5 分钟。适配器异常只把来源标为降级，不阻断核心功能。MySQL、Neo4j、Chroma 和 LLM 的状态初始为 `UNKNOWN`，收到真实 readiness 后才更新，避免伪报可用。

## 2. 前端与交互

全局右栏收缩宽度 72px，展开宽度约 420px。它展示 Orchestrator、8 个 Agent 的角色和目标、状态、当前动作、目标、原因码、置信度、耗时、注册工具、证据、数据源、事件时间线以及建议的接受、忽略和撤销操作。

布局在宽屏使用右侧停靠，在中等桌面使用覆盖面板，在小屏使用底部抽屉。推荐页旧 `AgentStage.vue` 文件被保留，但不再占据主布局。

动态交互只消费白名单 Directive。自动应用要求置信度不低于 0.75、连续两次稳定观察、至少 30 秒保持期；忽略或撤销后同类策略 10 分钟内不再自动应用。任何建议都不能自动跳转、修改任意 DOM 或发送推荐/反馈 POST，用户明确选择始终优先。

视觉已统一为浅色蓝白系统：页面 `#F6F9FC`、卡片白色、主色 `#2563EB`、系统无衬线字体、正文至少 16px、主要触控目标至少 52px。首页、推荐说明、图谱和馆藏图表均改为蓝/青/靛编码。

## 3. API 边界

- `POST /api/v1/agent-workspaces`
- `GET /api/v1/agent-workspaces/{workspace_id}`
- `GET /api/v1/agent-workspaces/{workspace_id}/events`
- `POST /api/v1/agent-workspaces/{workspace_id}/observations`
- `POST /api/v1/agent-workspaces/{workspace_id}/directives/{directive_id}/actions`
- `GET /api/v1/agents`

这些接口仅在显式研究组合根注入 Broker 时注册；默认 `backend.app.main:app` 不挂载，继续 fail-closed。SSE 使用身份 Header 和 `Last-Event-ID`，公开事件过滤 Prompt、模型原文、密钥、完整画像、SQL、Cypher 与内部数据库字段。
