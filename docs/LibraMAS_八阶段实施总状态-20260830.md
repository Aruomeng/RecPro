  机制和可复算性，不能作为准确率结论。

  `7fbb544b-538e-522d-b2f4-25a84daf9cc3`（hash

  `DRY_RUN`，不能直接执行。
- 生产需要 OIDC/JWKS 实际身份映射、TLS/Secret、独立恢复目标、正式只读图副本绑定、

- 本阶段文件删除、数据库记录删除、数据库删除、容器删除、数据卷删除均为 `0`。
- 本阶段 MySQL 写入、Neo4j 写入、Chroma 写入、Outbox claim 和业务 POST 均为 `0`。
- 本阶段新增 DeepSeek 网络请求为 `0`；常驻 Workspace 感知不调用模型。
- 不使用管理员凭据作为研究图读取凭据，不回退到未知权限身份。
- 不把密码、刷新令牌、完整证号、Prompt、模型原文、SQL、Cypher 或原始画像写入公开
  事件、日志或状态文档。
- 任何需要创建账号/会话、追加审计或业务事实、导入图谱、启用真实模型、创建基础设施
  或写入 Secret 的动作，都必须先提交新的精确 `plan_id + plan_hash` 并取得明确批准。
- 测试契约已与任务级只读快照复用实现对齐；后续若改变读取边界，必须同步更新性能证据，
  不通过修改历史数据或放宽安全校验解决。
