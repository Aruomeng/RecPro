# LibraMAS 首页摘要布局修复记录（2026-09-05）

## 问题

在 1280×720 的实际页面检查中，首页“全局 Agent Workspace”摘要使用 `auto 1fr auto` 三列布局。由于中间状态文本的最小内容宽度被压缩为约 39px，中文状态说明出现逐字竖排，违反大屏文字完整显示要求。

## 修复

只调整 `frontend/src/styles-v2/pages.css` 的中等桌面断点（721–1599px）：

- Workspace 标签独占一行。
- 状态说明与引导文案使用两个可伸缩列。
- 两列均允许安全换行，不设置固定高度或隐藏溢出。
- 移动端原有单列规则保持不变，宽屏 ≥1600px 的布局保持不变。

未修改 API、Agent 状态机、数据库、模型配置或任何业务事实。

## 验证

- 前端 Vitest：19 个文件、81 项通过。
- `vue-tsc --noEmit`：通过。
- 安全构建：`RECPRO_BUILD_RUN_ID=ui-layout-fix-20260905-001`，Vite 683 个模块构建通过；产物写入新的 `frontend/dist/ui-layout-fix-20260905-001/`，没有覆盖旧构建。
- 1280×720：摘要高度从 164.5px 降为 69.34px；状态文本宽度从 38.9px 增至 200.88px，不再竖排。
- 1920×1080：摘要高度 62px，正文宽度 363px；`body.scrollWidth == clientWidth`。
- 390×844：摘要采用单列自然换行，高度 135.14px；`body.scrollWidth == clientWidth`。
