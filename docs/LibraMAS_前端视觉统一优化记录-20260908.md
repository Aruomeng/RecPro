# LibraMAS 前端视觉统一优化记录（2026-09-08）

## 1. 本轮范围

本轮仅调整前端展示层，包括设计 Token、响应式布局、组件外观、图表展示参数、图标与交互动效。未修改后端、API 契约、路由行为、Pinia 业务状态、认证流程、请求参数、事件处理器或数据库逻辑。

安全计数：

- 删除文件：0。
- 数据库写入、更新或删除：0。
- DeepSeek 或其他模型请求：0。
- 容器、数据卷变更：0。

## 2. 实际优化内容

### 2.1 统一设计系统

- 统一为现代智慧图书馆的蓝白浅色体系：浅灰蓝背景、白色卡片、克制蓝色主色、青色辅助色和清晰语义状态色。
- 统一系统无衬线字体、标题层级、正文和辅助字号；可见正文不低于 14px，主要正文以 16px 为基准。
- 统一圆角、边框、阴影、间距和焦点样式，移除无意义的高亮、光晕和过度科技化装饰。
- 新增统一的线性 SVG 图标组件，替换导航、搜索、关闭、反馈和跳转位置混用的 Unicode 图形。

### 2.2 布局与可读性

- 修复导航栏、主内容和全局 Agent 工作栏在不同宽度下的占位关系。
- 首页采用 12 列响应式栅格，重新平衡搜索、知识图谱、指标、分类和核心入口的信息密度。
- 推荐结果、推荐理由、图书标题、Agent 说明和错误信息改为自然增高，不再被固定高度裁切。
- 知识图谱、阅读路径、馆藏洞察、系统状态、登录弹窗和详情抽屉均增加明确的窄屏降级布局。
- 4K 下扩大内容有效宽度和图表画布；移动端为底部导航与 Agent 抽屉保留安全区域。

### 2.3 有效交互反馈

- 为按钮、链接、卡片入口、图谱操作和 Agent 开关统一增加悬停、按下、键盘焦点和禁用反馈。
- 只有真实处于 `WORKING` 状态的 Agent 才显示克制动态反馈，避免伪造活跃状态。
- 支持 `prefers-reduced-motion`，用户偏好减少动效时自动停用非必要动画。
- 保留主次按钮层级，避免所有按钮使用相同的强视觉权重。

### 2.4 图表与知识图谱

- ECharts 统一为蓝、青、靛色主题，统一字体、Tooltip、Legend、坐标轴和节点标签字号。
- 调整图谱标签宽度、换行、重叠隐藏和高亮关系线，减少文字碰撞。
- 调整分类、通道、年代、主题等图表的有效画布和标签留白，完整信息继续通过 Tooltip 呈现。
- 图书程序化封面改用一致的蓝青配色，并保证标题与底色对比度。
