# LibraMAS 正式论文实验材料交接清单

更新时间：2026-09-01  
适用范围：`智能体 + 智慧图书馆 + 推荐` 的**确认性论文实验**。

## 结论与边界

本仓库已可运行 `DEVELOPMENT_PROXY` 开发性实验，用于验证实验流水线、消融配置、故障降级与可复现性。它由 `Lib/` 的 Topic、Category、SubjectCode 生成确定性代理标签，**不能**用作“真实读者推荐准确率提升”的论文结论。

启动确认性实验前，项目负责人必须提供下列五类冻结输入；本清单不能替代许可证、伦理审批、真实标注或用户同意。真实用户身份、身份映射、原始凭据和许可证原件不得提交到 Git。

## 交接目录与五类 Manifest

经授权、已脱敏的材料可放在 `data/evaluation/`；每个文件都要有 SHA-256，且所有路径均须为仓库内相对路径。

| 文件 | Schema | 必须由谁确认 | 核心内容 |
| --- | --- | --- | --- |
| `dataset_manifest.json` | `contracts/experiment/dataset-manifest.schema.json` | 数据负责人 | 数据来源、Track、输入文件哈希、匿名化、资源/匿名用户/行为/任务数量、确认性资格 |
| `license_manifest.json` | `contracts/experiment/license-manifest.schema.json` | 数据来源或伦理/版权负责人 | 每个来源的许可编号、用途范围、证据引用、限制与审批状态 |
| `annotation_manifest.json` | `contracts/experiment/annotation-manifest.schema.json` | 两名独立标注者与仲裁人 | 盲标注标签文件、标注者、可靠性指标、仲裁产物、测试集冻结状态 |
| `split_manifest.json` | `contracts/experiment/split-manifest.schema.json` | 实验负责人 | train/validation/test 哈希、时间边界、分组键、无重叠与无泄漏声明 |
| `config_manifest.json` | `contracts/experiment/config-manifest.schema.json` | 实验负责人 | Git 提交、干净工作区、依赖锁、配置包、策略/排序/提示词/图谱版本、随机种子和四份输入引用 |

## 不可替代的真实材料

1. **数据与许可**：提供可研究使用的脱敏交互/任务数据，或明确选择 `TRACK_I` 的外部客观数据；每个来源必须有可核验的许可或书面授权。
2. **标注**：至少两名相互独立的标注者；隐藏系统身份、排序位置和算法分数；保留原始标签，完成一致性计算及仲裁。
3. **冻结切分**：在查看测试指标前确定时间边界、分组键和测试集；不允许通过测试结果调整。
4. **实验配置**：冻结基线 B0–B3、Proposed 和消融配置，记录当前 Git commit、依赖锁、图谱版本与随机种子。
5. **隐私与伦理**：用户研究需保留知情同意与去标识化说明；研究导出只能使用不可逆 `user_research_id`，身份映射与实验输出分离保管。

## 建议的接收顺序

1. 先接收数据、许可与匿名化说明，建立 Dataset/License Manifest。
2. 冻结任务与候选池后，由两名标注者独立完成相关性和策略标注，再完成一致性与仲裁。
3. 生成并冻结 Split Manifest，确认无测试泄漏。
4. 最后冻结 Config Manifest；此时必须是已提交的干净工作区。
5. 运行只读输入门禁。只有输出 `READY_FOR_FORMAL_RUN` 才能申请正式运行 ChangePlan。

```bash
PYTHONPATH=. .venv-g1-final-py311/bin/python scripts/verify_evaluation_freeze_inputs.py \
  --run-id eval-inputs-<唯一编号> \
  --dataset data/evaluation/dataset_manifest.json \
  --license data/evaluation/license_manifest.json \
  --annotation data/evaluation/annotation_manifest.json \
  --split data/evaluation/split_manifest.json \
  --config data/evaluation/config_manifest.json
```

该检查器只读取五类 Manifest 及其引用文件，并在新目录生成一份证据报告；不连接数据库、不调用模型、不会删除或覆盖历史输入与运行产物。

## 提交前核对

- [ ] 数据集的 `confirmation_eligible=true`，且来源不是 synthetic/demo。
- [ ] 所有输入文件、标签、切分和配置都有匹配的 SHA-256。
- [ ] License Manifest 的 `approval_status=VERIFIED`。
- [ ] 两位及以上独立标注者、盲化条件、可靠性阈值和仲裁均已完成。
- [ ] Split 标记为 `frozen=true`，并声明 no-overlap、无用户/分组泄漏、事件唯一。
- [ ] Config 标记为 `FROZEN`，Git commit 为 40 位哈希且工作区干净。
- [ ] 输入门禁返回 `READY_FOR_FORMAL_RUN`。
- [ ] 正式运行前另行生成精确 ChangePlan：新 Run ID、输出目录、模型请求上限、任何数据库/Neo4j 写入上限与逐表对账方案。
