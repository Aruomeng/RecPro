## 2. 实际功能产出

- 新增统一 v2 图路径引用契约，可从推荐卡路由到确定的 source/target 路径。
- Neo4j Recall 与 Exploration Path Reader 使用相同引用算法。
- CandidateRecallAgent 拒绝缺失路径、非法路径或版本不匹配的 Graph 得分。
- 推荐证据公开返回：
  - `graph_version`
  - `graph_path_refs`
  - `graph_path_coverage_state`
- 推荐响应、MySQL 投影和幂等回放均保留完整 Graph 证据。
- 前端可从推荐卡进入知识图谱页，并加载和高亮对应路径。
- 阅读路径稳定形成“入门—进阶—深化”三组，不随机分组。
- 执行器区分完整结果回放和任务状态 GET，避免将状态接口缺少结果列表误判为证据丢失。
