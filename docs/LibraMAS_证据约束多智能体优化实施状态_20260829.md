代码、无写入测试、浏览器验收与开发性实验均完成。2026-08-29 精确批准后，Workspace 审计已追加并对账，Neo4j v2 已追加并证明 v1 零变化。知识审核迁移在创建视图时被最小权限拒绝，只留下两张空表；提案、权限事实和迁移标记均为 0，现等待新的 fail-forward successor 精确批准。现有 v1 图、历史事实、容器和数据卷没有被修改或删除。

## 2. 阶段产出

### 阶段 1：正确性与安全基础

- 同步与异步推荐统一从服务端 Principal 和个性化授权构造命令。
- 客户端不能覆盖 `_personalization_enabled`、`profile_empty`、`user_id`、`profile_version`。
- Guest/未授权会话不读取长期画像，画像摘要不进入 DeepSeek 上下文。
- Neo4j 项目只读身份配置与权限验证代码已建立；管理员凭据不作为研究读取默认值。
- Workspace Audit 已接入显式研究组合根，但四重门禁默认关闭。

### 阶段 2：真实 Workspace Agent 策略平面

- 新增有界异步调度器：全局 16 个观察任务、每 Workspace 1 个、积压 64 个。
- Route/readiness/resource/graph/query Observation 使用固定 Handler 和真实只读端口。
- SSE 明确区分实时 dispatch、历史真实动作回放、规则回退、降级和失败。
- SessionTopicGraph 最多 64 节点、128 边；Guest 自然过期且不持久化。
- 8 个业务 Agent 空闲时保持 `IDLE`，Orchestrator 单列但不计为第九个 Agent。

### 阶段 3：知识图谱 v2 与多跳证据

- 新建 `Work` 与 `INSTANCE_OF`，不伪造缺少真实副本编号的 Item。
- dry-run：78,129 节点、206,848 关系；相对 v1 增加 14,741 Work 与 14,983 INSTANCE_OF。
- 生成 262 条冲突审核提案：缺作者 50、ISBN 冲突 143、出版社冲突 69。
- 公共路径查询固定最多 3 跳、10 路径、60 节点、120 边、3 秒。
- v2 Graph 候选没有合法路径时不贡献图谱分数。

### 阶段 4：馆员知识治理闭环

- 完成 Proposal、Action Fact、当前状态推导、内存/MySQL Adapter、权限、API 和馆员前端页。
- Reader、Guest、Agent 无审核动作权限；馆员动作只追加事实。
- `APPROVE` 不直接修改 Neo4j，只能作为下一图版本的候选输入。

### 阶段 5：全页面联动与大屏验收

- 推荐卡显示真实 Neo4j 路径引用数量，并可进入图谱核验上下文。
