4. 为测试读者追加四项个性化授权，并在授权后写入声明画像投影。
5. 在授权撤回后验证不再产生新的长期学习事实。

这些动作需要绑定当前代码提交的新 successor ChangePlan，精确列明测试 UUID、预计各表
追加行数、允许的受控状态更新、凭据交付方式、回滚/失败处理、DeepSeek 请求上限（本阶段
默认为 0）和逐表前后计数。获得该 successor 的 `plan_id + plan_hash` 明确批准前，执行
器必须保持只读/内存模式。
